# gfwlist-mirror

一份「通常访问不了的网站」名单的**镜像**。它存在的唯一理由是让一台自编译的
ShadowsocksX-NG 有一个**自己的、可维护的**名单来源。

- `gfwlist.txt` —— 名单本体，base64 编码的 Adblock Plus 语法（上游格式原样保留）。
- `meta` —— 这份名单从哪来、什么时候取的、多少条、sha256。

## 怎么更新

名单由 [shadowsocksx-ng](https://github.com/creatorliao/shadowsocksx-ng) 那个仓的
`tools/refresh-gfwlist.sh` 抓取并写入，然后推到这里。**不要手工改 `gfwlist.txt`**：
它下一次刷新就会被覆盖。

## 这是什么，不是什么

- 是：一份**公共**的、社区维护的网站清单。
- 不是：你的代理配置、节点信息、密码。这个仓**只有名单**。

## 这个仓为什么是公开的

因为它要能被**不需要登录**地读取。名单本身是公开信息（上游本来就公开分发），
而主仓 `shadowsocksx-ng` 保持**私有** —— 那里面有构建配方与个人配置。

## 它和「用户自己写的规则」的关系

没有关系。App 里用户自己写的网站规则存在本机，优先级**高于**这份名单，
更新名单**永远不会**改动用户写的规则。
